# コメント音声提示プレイヤー（Android版・モード6／モード7）

PC版プロトタイプのうち、モード6・モード7だけを Android で動かせるようにした Web アプリ（PWA）です。
動画は wK-rbvTOgZk 固定。AI紐付け済みデータ（mode4_schedule_wK-rbvTOgZk_ai.json）とTTS音声（69ファイル）をそのまま同梱しています。

## 起動方法（いちばん簡単）
1. PCでこのフォルダの `start_server.bat` をダブルクリック（Node.js が必要。PC版で使っているもので可）。
2. 画面に表示される `http://192.168.x.x:8080` を、同じWi-FiのAndroidのChromeで開く。
3. 「開始」をタップ → 動画の再生ボタン（またはアプリの「▶ 再生」）。

## インターネット上に置く場合（PCなしで使いたいとき）
このフォルダをそのまま GitHub Pages / Netlify / Cloudflare Pages などの静的ホスティングに置きます（HTTPS）。
Chrome で開き、メニュー →「ホーム画面に追加」でアプリとして起動できます。音声・データは端末にキャッシュされます
（※動画そのものはYouTube再生のためオンライン必須）。更新したら `sw.js` の `CACHE` 名を変えてください。

## 操作
- モード6: タッチエリアを押している間、動画が止まり「現在位置より前で最も近い未読AIコメント」を読み上げ。押し続けると次々に遡って読み、離すと動画再開。
- モード7: 動画を再生すると、AI紐付けタイミングで自動停止→読み上げ→自動再開。
- 「最初から」: 読み上げ履歴・クールタイムをリセットして0秒に戻る（参加者を替えるとき用）。
- 設定: TTS音量／TTS速度／モード6・7の読上時間上限／モード7のクールタイム（端末に保存）。

## 注意
- 読み上げ音声が0バイトの6件（comment_0, 1, 24, 27, 33, 53）は端末の音声合成（Web Speech）で代替します。
- 動画が埋め込み不可の場合はエラー表示と「YouTubeで開く」リンクを出します。
